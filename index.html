探索後整理 看看火力發電中的能量怎麼轉換

火力發電是利用燃料中儲存的 化學能， 經過燃燒轉換成 熱能。 熱能使水產生高溫蒸氣，蒸氣再推動汽輪機旋轉， 最後由發電機將旋轉的機械能轉換成電能。

化學能 → 熱能 → 機械能 → 電能
再想一下： 如果燃料正常燃燒、蒸氣也正常產生， 但發電機沒有獲得足夠的旋轉機械能， 你會先檢查哪一個能量轉換階段？

探索後整理 看看風力發電中的能量怎麼轉換

流動的空氣具有動能。 當風推動葉片旋轉時，部分能量傳遞給風機的旋轉系統， 形成機械能，再由發電機轉換成電能。

風的動能 → 機械能 → 電能

探索後整理 看看水力發電中的能量怎麼轉換

位於較高處的水具有重力位能。 水向低處流動時，部分位能轉換成水流的動能； 水流再將能量傳遞給水輪機，使水輪機旋轉， 最後由發電機產生電能。

重力位能 → 動能 → 機械能 → 電能

探索後整理 看看太陽光電中的能量怎麼轉換

太陽光電與火力、核能、風力或水力不同， 太陽能電池可以將光能直接轉換成電能， 不需要先經過汽輪機、水輪機或風機等旋轉機械設備。 太陽能板產生的直流電，再經過逆變器轉換成交流電， 才能進一步輸送與使用。

光能 → 直流電 → 交流電 → 電網

Credit: EnergyEncyclopedia.com
探索後整理 看看 Tokamak 為什麼需要高溫電漿與磁場

核融合要發生，兩個帶正電的原子核必須彼此非常接近。 但原子核之間會受到 庫侖斥力， 因此需要讓粒子具有足夠高的能量， 才能提高它們接近彼此並發生核融合的機會。

提高粒子能量 → 更有機會克服排斥 → 接近到核力作用範圍 → 提高融合機率

在極高溫下，原子中的電子會與原子核分離， 形成由帶電粒子組成的 電漿。 因為這些粒子帶電，所以可以利用 磁場 影響它們的運動方向， 協助把高溫電漿限制在一定範圍內。

高溫

提高粒子的平均動能。

電漿

由帶電粒子組成的高能狀態。

磁場

影響帶電粒子的運動，協助約束電漿。

真空

減少背景氣體造成的不必要碰撞與能量損失。
